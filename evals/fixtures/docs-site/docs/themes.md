# Themes

Peridot ships with 3 bundled themes:

- `citrine` — the default theme. A light, single-column reading layout.
- `lapis` — a dark theme with a fixed navigation sidebar.
- `malachite` — a high-contrast, print-friendly theme.

Pick one with the `theme` key in `peridot.yml`:

```yaml
theme: lapis
```

Custom themes are not supported yet; the bundled set is the full list.
