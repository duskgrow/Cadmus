# Peridot

Peridot is a static site generator for small documentation projects. You
write plain Markdown, and Peridot turns it into a fast HTML site with a
navigation sidebar and full-text search.

- No database and no server-side code: the output is plain HTML and CSS.
- One configuration file, `peridot.yml`.
- A live-reloading dev server for local writing.

To get started, see `docs/getting-started.md`. To deploy a site, see
`docs/deployment.md`.
