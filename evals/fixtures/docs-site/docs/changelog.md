# Changelog

## 0.9.0

- Add the `--strict` flag to `peridot build`: warnings now fail the build.
- The dev server now reloads browser tabs after every rebuild.

## 0.8.0

- Breaking change: the `peridot publish` subcommand is renamed to
  `peridot deploy`. Update any scripts that still call `publish`.
- Add the `permalink` configuration key.

## 0.7.0

- First tagged release: `new`, `build`, `serve`, and `publish`.
