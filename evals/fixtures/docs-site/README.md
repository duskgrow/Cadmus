# Peridot documentation

This repository is the documentation source for Peridot, a static site
generator for small documentation projects. The site is built with Peridot
itself.

## Layout

- `peridot.yml` — the site configuration (name, theme, navigation)
- `docs/index.md` — the home page
- `docs/getting-started.md` — installation and your first site
- `docs/configuration.md` — every configuration key and its default
- `docs/themes.md` — the bundled themes
- `docs/cli.md` — the command-line reference
- `docs/deployment.md` — deploying a built site
- `docs/changelog.md` — the release history

## Previewing the docs

```sh
peridot serve
```

Then open http://localhost:7180.
